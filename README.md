# Weekly Manager

Weekly Manager is a Playnite generic plugin for managing recurring weekly game activities, resets, reminders, status, and per-game checklists.

**Status:** Early development. The repository currently contains the initial buildable plugin foundation.

## Planned Features

- Configurable weekly reset schedules
- Playnite notifications
- `WEEKLY READY` / `COMPLETE` status
- Per-game weekly checklists
- Optional secondary reminders
- Optional theme integration, such as FusionX
