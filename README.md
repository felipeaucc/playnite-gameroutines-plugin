# Weekly Manager

Weekly Manager is a Playnite generic plugin for managing recurring weekly game activities, resets, reminders, status, and per-game checklists.

**Status:** Early development. Phase 1 provides configurable weekly resets, INCOMPLETE/COMPLETE state, internal Playnite notifications, optional secondary reminders, and optional `Weeklies Available!` tag synchronization.

## Planned Features

- Configurable weekly reset schedules
- Playnite notifications
- INCOMPLETE / COMPLETE weekly state
- Optional `Weeklies Available!` tag synchronization
- Per-game weekly checklists
- Optional secondary reminders
- Optional theme integration, such as FusionX
